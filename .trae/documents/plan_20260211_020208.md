# Replace N8N with Native Tauri Implementation & Env Config

This plan aims to replace the heavy N8N dependency with a lightweight, native Rust implementation for daily report scheduling and LLM interaction, while adding support for environment variable configuration.

## 1. Backup & Preparation
- [ ] **Backup Prompts**: Extract the "Efficient R&D Technical Expert" system prompt from `src/config/workflow.ts` to a new constant in Rust.
- [ ] **Define New Settings & Env Support**:
    - Add `dotenvy` crate to `tauri/Cargo.toml` to support `.env` files.
    - Update `tauri/src/config/setting.rs` to load settings with Env fallback:
        - Check `LLM_API_KEY` and `LLM_BASE_URL` env vars.
        - `daily_report_time` (default "18:00")
        - `llm_api_key` (from env or settings store)
        - `llm_base_url` (from env or default `https://api.deepseek.com`)
    - Expose an `is_llm_env_configured` boolean flag to the frontend.

## 2. Remove N8N Components
- [ ] **Backend Cleanup**:
    - Delete `tauri/src/service/workflow/`.
    - Delete `tauri/src/task/tick_check_n8n_process/`.
    - Delete `tauri/src/task/call_n8n_workflow_webhook/`.
    - Remove N8N commands from `tauri/src/bridge/cmd.rs`.
    - Clean up `tauri/src/service/download/installable.rs`.
- [ ] **Frontend Cleanup**:
    - Delete `src/store/modules/n8n.ts`.
    - Delete `src/config/workflow.ts`.
    - Remove N8N-related UI: `src/ui/setting-n8n-card.tsx`.

## 3. Implement Native Features (Rust)
- [ ] **Scheduler Service**:
    - Create `tauri/src/service/scheduler/mod.rs`.
    - Implement a background loop (1-minute interval) that checks `daily_report_time`.
    - Add `restart_scheduler` command.
- [ ] **LLM Client Service**:
    - Create `tauri/src/service/llm/mod.rs`.
    - Implement `generate_daily_report()`:
        1.  **Aggregate Data**: Reuse logic from `get_summary_prompt`.
        2.  **Call LLM**: Use `reqwest` with configured API Key/Base URL.
        3.  **Save Report**: Store result in database.

## 4. Frontend Integration
- [ ] **Settings UI**:
    - Create `src/ui/setting-report-card.tsx`.
    - Add inputs for Schedule Time.
    - Add inputs for API Key (disable/hide if configured via env).
- [ ] **Startup Flow (Initiator)**:
    - Update `src/layouts/components/initiator.tsx`:
        - Check `is_llm_env_configured` flag.
        - If true, **skip** the DeepSeek configuration step.
- [ ] **Report Generation**:
    - Update "Generate Report" button to call `generate_daily_report`.

## 5. Verification
- [ ] Verify `.env` configuration allows skipping setup.
- [ ] Verify manual and scheduled report generation works.
- [ ] Confirm N8N is fully removed.
