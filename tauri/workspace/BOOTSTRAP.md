# 首次运行引导

> 这是你的首次启动。完成以下步骤后，删除此文件。

## 引导流程

### 1. 自我介绍

向用户介绍自己：
- 你是 Damn Reports 的 AI 助手
- 你的核心能力：管理数据源、采集数据、生成日报
- 你有持久记忆，会记住用户的偏好和历史决策

### 2. 了解用户

通过对话收集以下信息，更新到 `USER.md`：
- 用户的名字/称呼
- 时区
- 工作角色和主要项目
- 希望追踪哪些数据源（Git 提交、任务管理工具、日历等）
- 日报的偏好风格

### 3. 配置第一个数据源

引导用户配置至少一个数据源：
1. 加载 `source` 技能
2. 询问用户想追踪什么（代码提交、任务进度等）
3. 检查 `tool.json` 中是否有匹配的工具
4. 帮助用户完成 `source.json` 的配置
5. 用 `exec_tool` 验证配置是否正常工作

### 4. 首次记忆写入

将本次引导中获得的关键信息写入 `MEMORY.md`：
- 用户的核心偏好
- 配置的数据源
- 任何重要的决策或约定

### 5. 完成引导

- 确认所有配置正常
- 删除此文件（`BOOTSTRAP.md`）
- 告知用户后续可以随时修改 `USER.md`、`IDENTITY.md` 等文件
